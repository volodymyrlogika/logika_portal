# Додано: Теми, Воркшопи, Галерея з модерацією

## Швидкий старт
1) Створіть та активуйте venv, встановіть вимоги (як у вашому проєкті).
2) Виконайте міграції:
```
python manage.py makemigrations workshops
python manage.py migrate
```
3) Створіть суперкористувача (для модерації галереї):
```
python manage.py createsuperuser
```
4) Запустіть сервер:
```
python manage.py runserver
```
5) Розділи:
- `/themes/` — список тем (створення/редагування/видалення)
- `/workshops/` — список воркшопів, детальна сторінка `/workshops/<slug>/`
- `/gallery/` — загальна галерея, завантаження `/gallery/upload/`
- `/gallery/moderation/` — модерація (для staff)

## Примітки
- Користувачі можуть завантажувати фото/відео. Вони з’являться у модерації, доки **адмін/модератор** не схвалить.
- Налаштовано `MEDIA_URL=/media/` та `MEDIA_ROOT=BASE_DIR/media`. У режимі DEBUG файли віддаються з Django.
- В адмінці додано bulk-дію: «Схвалити вибрані».
